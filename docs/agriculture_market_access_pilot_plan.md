# Agriculture Market Access — Pilot Plan

## Scope
Pilot market-access workflows inside the existing Skills and Enterprise Portal for one province/district cohort.

## Participants
- Field agents / cooperative officers (agent-assisted registration)
- Market-access officers (verification, matching, consent)
- Price officers (draft / verify / publish)
- Verified crop buyers (demands)
- Farmers without smartphones (SMS / USSD / agent)

## Success measures (non-sale metrics allowed)
- Farmers registered and phone-reachable
- Verified buyers onboarded
- Produce listings active vs expired
- Matches suggested vs officer-approved
- Consents accepted vs declined
- Price checks via SMS/USSD
- SMS delivery success rate

Do **not** treat matches or price checks as sales KPIs.

## Exit criteria to production
See acceptance report. Live USSD optional if credentials pending.
