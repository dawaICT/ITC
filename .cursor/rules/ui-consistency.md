# UI Consistency Rules

WUCPortal currently has inconsistent inline CSS and repeated UI patterns.

When improving UI:
- Move reusable styling into external CSS files.
- Do not leave new inline CSS unless unavoidable.
- Keep headers, cards, modals, sidebars, buttons, forms, and tables consistent.
- Use a clean academic/professional design.
- Avoid emojis, excessive icons, AI-looking text, and unnecessary decoration.
- Preserve existing navigation behaviour unless fixing a bug.
- Make pages printable where reports are involved.
- Reports must be filterable, printable, readable, and consistent.
