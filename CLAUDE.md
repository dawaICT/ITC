# Project Rules

- This is a PHP + MySQLi + XAMPP project.
- Use prepared statements for all SQL queries.
- Do not change database connection files unless specifically asked.
- Keep existing UI design unless the task is about design.
- When debugging, first identify the cause, then fix with minimal changes.
- After code changes, explain what was changed and why.

# Common Commands

- PHP files are inside the project root.
- Database is MySQL/MariaDB through XAMPP.
- Local URL format: http://localhost/wucportal/
