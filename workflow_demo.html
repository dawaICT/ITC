The Workflow

1 Create Department

Fill in the simple form with essential information:

  • Department Code (e.g., CS01)
  • Department Name (e.g., Computer Science)
  • Faculty
  • Head of Department

Clean, focused department form

2 Smart Success Prompt

After saving, see an intelligent notification:

Department "Computer Science" created successfully!
Would you like to add programs to this department?
3 Quick Add Programs Modal

Modal opens with department pre-selected:

Add Programs to Computer Science

Department automatically selected • Fast entry • Add multiple
4 Rapid Program Entry

Add programs quickly, one after another:

Program 1: BSC-CS → Submit → Success! ✓
Program 2: DIP-IT → Submit → Success! ✓
Program 3: CERT-WEB → Submit → Success! ✓
// Add as many as needed!

Pro Tip: Form clears after each submission but keeps department selected!

5 Complete & Done

When finished:

  • Click "Close" to finish
  • Department table automatically refreshes
  • Ready to create another department
You can also skip adding programs and add them later via the Programs page!
